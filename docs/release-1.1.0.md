ShardKeeper 1.1.0 for WoW 3.3.5a (WotLK).

- Redesigned settings with live shard count, presets and automatic saving.
- Default WoW UI and automatic ElvUI styling.
- Pause/resume with immediate cleanup of existing excess.
- New active/paused icons and square minimap support.
- Safer one-at-a-time cleanup, with fixes for rapid shard gains and overlapping inventory updates.
- Targets from 0 to 32, matching the normal WotLK limit.

### Install
Extract **ShardKeeper-1.1.0.zip** into `Interface/AddOns/`, then restart WoW. The path should be `Interface/AddOns/ShardKeeper/ShardKeeper.toc`.

Replace the old `ShardKeeper` folder when updating; saved settings are retained.

Tested in-game on Warmane. Compatible with the default interface and ElvUI. This release targets the 3.3.5a client, not Vanilla 1.12 or modern Classic.
